# Suikoden I research data provenance

`Suikoden1ResearchData.json` contains short factual ID-to-name mappings mechanically transcribed from asilverthorn's unlicensed `Suikoden1_Remaster_Save_Editing.md` at commit `9a216b93a7bc3d9c062700e4e12b18f9e36cbdf6`.

The source repository had no obvious license file. This project does not claim that its prose is MIT, does not reproduce that prose, and uses these labels as credited research data. Save paths, shapes, counts, and values exposed for editing are separately checked against supplied encrypted saves. Weapon names and undocumented meanings are deliberately absent rather than guessed.
